# قوة الآن 💪 — النسخة V16

هذه النسخة مبنية فوق المشروع الحالي، وليست إعادة كتابة من الصفر. تم الحفاظ على مفتاح تخزين المهام `quwat_alaan_tasks_data` وعلى نموذج المهمة ومعرّفات المهام والإشعارات المحلية.

## إعداد نيكو للاستخدام الشخصي

الاتصال المستخدم هنا هو Gemini Developer API المباشر للاختبار الشخصي فقط، لأن Firebase AI Logic طلب إعداد فوترة في مشروعك. لا يوجد مفتاح داخل هذا الأرشيف.

بعد بناء التطبيق وتثبيته، افتح «الإعدادات → إعداد اتصال نيكو»، والصق المفتاح في الحقل المخفي، ثم اضغط «حفظ واختبار الاتصال». لن تحتاج إلى تعديل أي ملف Dart، ولا يوجد مفتاح داخل ZIP أو GitHub. يحفظ التطبيق المفتاح محليًا على الهاتف؛ وهذا مناسب للاستخدام الشخصي، لكنه ليس حماية مطلقة لأن المفتاح قابل للاستخراج من تطبيق الهاتف.

إذا رفض النموذج الموجود في `ai_assistant_service.dart` الطلب، راجع قيمة `model` هناك واستخدم اسم نموذج متاح في حسابك؛ لا يوجد ادعاء بأن كل حساب يملك نفس النماذج أو الحصص.

## ما تم تنفيذه

- شاشة إعداد أول تشغيل وحفظ الاسم محليًا مع الحفاظ على المستخدمين الحاليين.
- اسم العرض في الصفحة الرئيسية، مع إمكانية تعديله من الإعدادات.
- ثلاثة أوضاع للثيم: فاتح، داكن، وتلقائي حسب النظام، مع حفظ الاختيار.
- شريط تنقل سفلي، وزر إضافة مهمة في المنتصف، ودخول نيكو من أيقونة الاختيار.
- بطاقة أكبر لـ «ماذا أفعل الآن؟» تعرض المهمة الحالية والوقت المتبقي من الوقت الحقيقي أو المهمة القادمة.
- تحديث خفيف للبطاقة كل دقيقة، وإعادة الحساب عند العودة للتطبيق.
- واجهة محادثة مشتركة لـ «نيكو العام» و«مساعد تنظيم الوقت».
- اتصال حقيقي بـ Gemini عند وجود مفتاح وإنترنت، مع رسائل عربية لفشل الاتصال والمهلة والحصة.
- سياق محدود لمساعد تنظيم الوقت من بيانات المهام المحلية فقط.
- لا ينفذ نيكو تعديلات مهام تلقائيًا؛ لا توجد وظيفة حفظ من النموذج في هذه النسخة.
- زر ميكروفون يبدأ التعرف الصوتي فقط، دون أصوات من التطبيق، ويظهر النص في حقل الكتابة قبل الإرسال.
- قراءة الرد اختيارية عبر `flutter_tts`، وليست محادثة Live API مباشرة.
- خريطة اليوم تدعم السابق/اليوم/التالي وتعرض الفترات الفارغة.
- الحفاظ على قنوات البداية والنهاية والتأجيل وإلغاء إشعارات المهمة قبل إعادة جدولتها.
- تحسين تحمل قراءة بيانات المهام القديمة دون تغيير مفاتيح التخزين.

## ما لم يُدّعَ تنفيذه

- لا توجد محادثة صوتية مباشرة Live API في هذه النسخة.
- لا توجد Firebase أو مصادقة أو نسخ احتياطي.
- لا يتم اعتبار المهمة مكتملة عند انتهاء وقتها.
- لا يتم نقل المهام غير المكتملة تلقائيًا.
- في سجل Klencod الأخير لم توجد أخطاء Dart، بل 21 ملاحظة warning/info جعلتها Workflow السابقة قاتلة. تم تغيير أمر التحليل في V16 إلى `flutter analyze --no-fatal-warnings --no-fatal-infos` حتى لا تمنع الملاحظات غير القاتلة بناء APK.

## خطوات Klencod

1. فك ضغط ZIP وافتح مجلد `quwat_alaan_final`.
2. بعد التثبيت أضف مفتاحك من «الإعدادات → إعداد اتصال نيكو» داخل التطبيق.
3. دع Klencod يشغل `pub get` تلقائيًا.
4. استخدم Build APK داخل Klencod.
5. إذا فشل الاتصال بنيكو، راجع اسم النموذج والحصة والإنترنت. لا تعرض المفتاح في رسالة الخطأ.

## الاختبارات التي نُفذت هنا

- فحص بنية ملفات Dart وعددها وتوازن الأقواس.
- فحص XML الخاص بـ AndroidManifest.
- التحقق من أن `applicationId` و`namespace` هما `com.quwatalan.app`.
- التحقق من `minSdk = 21` و`targetSdk = 35` و`compileSdk = 36` وJava/Kotlin 17.
- التحقق من عدم وجود مفتاح حقيقي داخل المشروع.
- اختبار سلامة أرشيف ZIP بعد الضغط.
